If they ask

Why still NSGs? Both must allow. NSGs cover unlabelled resources and give defence in depth.

Why buy Network Firewall? ZPR doesn't inspect content: no threat signatures, URL filtering or TLS inspection.

Unlabelled Test VM? Still blocked. The database's label protects it. We label the Test VM so the intent is explicit.

Does it filter the internet? Don't claim it. The demo proves separation between private workloads across the DRG.

How fast? Labels take a minute or two. The first check right after labelling may still say REACHABLE.

If they ask

Masking vs encryption vs redaction? Encryption protects stolen files; authorised users still see real data. Redaction hides values on screen; data is still real. Masking replaces the data in the copy.

Can we unmask? No, by design. The source stays untouched; mask a fresh copy at each refresh.

Does it change the database itself? Yes, in place. That's why it only ever runs on the test copy, never production.

Why keep CUSTOMER_ID? The joins. Real systems mask keys consistently instead.

Cost? Most Data Safe features are included for OCI databases; check the price list before quoting.
